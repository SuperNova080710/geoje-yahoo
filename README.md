# 거제, 가을의 끝에서

2026년 11월 21–23일 거제·통영 2박 3일 여행 계획을 공유하는 정적 웹사이트입니다. 모바일 우선 화면에서 날짜별 방문 순서, OpenStreetMap 지도, 식당·카페 후보를 탐색할 수 있습니다.

## 기능

- 날짜 탭을 선택하면 지도와 일정, 식당 후보가 함께 바뀝니다.
- 일정 항목을 누르면 해당 지도 지점이 강조됩니다. 지도 팝업의 링크는 정확한 위치 검색으로 연결됩니다.
- 식당 후보를 누르면 지도에서 해당 지역의 개략 위치가 강조됩니다. 팝업의 검색 링크로 정확한 위치를 확인할 수 있습니다.
- 지도상의 점을 잇는 선은 **방문 순서의 개략적인 연결선**이며 자동차 도로 안내가 아닙니다.
- 날짜 선택은 URL 해시(`#day-1` 등)에 담겨 공유됩니다.
- `prefers-reduced-motion` 설정에서는 장식 애니메이션을 줄입니다.

## 실행과 배포

별도 설치나 빌드가 필요하지 않습니다. 정적 파일 `index.html`, `styles.css`, `app.js`를 웹 서버에 올리면 됩니다. Vercel에서는 이 저장소를 연결해 프레임워크를 **Other**로 선택하고 루트 디렉터리를 그대로 사용하세요. 프로덕션 브랜치는 `main`으로 지정하면 됩니다.

지도의 Leaflet 자산, OpenStreetMap 타일, Google Fonts는 외부 서비스에서 로드됩니다. 네트워크가 제한된 환경에서는 지도 대신 검색 안내가 표시됩니다.

## 콘텐츠 관리

`app.js`의 `places`와 `days`를 수정합니다. 지도 좌표 일부는 여행 동선을 소개하기 위한 개략적인 위치입니다. 정확한 길찾기는 각 팝업의 지도 검색 링크를 이용하세요. 식당 영업·메뉴, 유람선 출항 및 ATV 운영은 방문 전 다시 확인해야 합니다.

## 라이선스 및 자료

웹사이트의 사용자 정의 선형 애니메이션은 이 프로젝트에서 새로 작성했습니다. `lucasmarkes/hairline` 코드를 복사하거나 포함하지 않았습니다. 지도 데이터 © OpenStreetMap contributors. Leaflet은 BSD-2-Clause 라이선스입니다.
